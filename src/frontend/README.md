# GameCore Frontend

React + TypeScript + Vite administrative interface for GameCore.

## Current toolchain

- React 19.3
- TypeScript 7.0
- Vite 8.3

## Run

```powershell
cd src/frontend
npm install
npm run dev
```

The default API URL is `http://localhost:5152`. Override it with `VITE_API_URL` when necessary.
